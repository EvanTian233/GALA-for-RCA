# Data Directory

`annotated_dataset.csv` is committed: it holds the human-written gold-standard incident
summaries and remediation recommendations used as the evaluation reference. See
[../annotation_guidelines.md](../annotation_guidelines.md) for how it was produced.

Downloaded benchmark datasets land in `data/RCAEval/` and are gitignored. See the main
[README](../README.md) for the download command.
